PJFree - PJLink Projector (Class 1)

Free PJLink projector control for Control4. Source, updates and bug reports: github.com/jwheeler188/PJFree

Generic IP driver for any projector that supports PJLink (Epson, Sony, NEC/Sharp, Panasonic, Optoma, Hitachi/Maxell, Canon, Christie, BenQ, etc.). TCP port 4352.

AI code generation was used in the production and testing of this driver. No warranty is provided; please report bugs at github.com/jwheeler188/PJFree/issues so the driver can be improved. Public domain (The Unlicense).

Tested on Control4 with a Panasonic PT-VMZ51S. Should work with any PJLink projector: run List Projector Inputs to see the available input codes, then edit the PJLink Code properties.

Setup

  1. Enable PJLink on the projector (network menu). Note the PJLink password if one is set. Make sure network standby / "standby mode: communication on" is enabled so the projector answers while off.
  2. Enter the projector's IP Address in properties (or bind it under Connections > Network).
  3. Enter the Password if PJLink authentication is on. Leave blank if off.
  4. Bind video sources to the HDMI / RGB / Video inputs under Connections > Control/AV, and add the projector as the room's video endpoint.
  5. Press Query Status to confirm Projector Name, Power State and Lamp Hours populate.

Input codes

Each input's PJLink Code property sets what is sent for INPT. Standard ranges: 1x = RGB, 2x = Video, 3x = Digital (HDMI/DVI/HDBaseT), 4x = Storage, 5x = Network. Defaults are HDMI1=31, HDMI2=32, HDMI3=33, RGB=11, Video=21, LAN=51. Run the List Projector Inputs action with Lua output open to see the codes your projector actually reports, then adjust.

Properties

  • Send Auth With Every Command - leave No (per spec). Set Yes only if a projector rejects the second command in a session with ERRA.
  • Poll Interval - 0 disables polling. Polls power (and input when on); lamp/error status every 10th poll.
  • Debug Mode - prints TX/RX to the Lua output window.

Programming

Commands: Power On, Power Off, AV Mute On, AV Mute Off, Send PJLink Command (e.g. AVMT 31, POWR ? - no %1 prefix needed).

Variables: POWER_STATE, POWER_ON, INPUT, AV_MUTE, LAMP_HOURS, ERROR_STATUS.

Notes

  • Selecting a source while the projector is off powers it on, and the input command is retried every 5 s (up to ~2 min) while the projector reports busy (ERR3) during warm-up.
  • Warming up counts as ON and cooling as OFF for the room.
  • The driver connects on demand and drops the socket when idle, which avoids the projector's 30-second idle timeout.
